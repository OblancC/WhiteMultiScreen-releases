# WhiteMultiScreen

Instaladores do **WhiteMultiScreen**: várias contas de jogos de navegador lado a lado, numa janela só, cada uma com sessão própria.

**[Baixar a versão mais recente](https://github.com/OblancC/WhiteMultiScreen-releases/releases/latest)** (arquivo `WhiteMultiScreen-Setup-x.y.z.exe`).

- O app avisa quando sai uma versão nova e atualiza sozinho.
- Seus dados ficam em `%APPDATA%\WhiteMultiScreen` e são mantidos nas atualizações.
- Na primeira vez o Windows pode mostrar "O Windows protegeu o computador" (o instalador não tem assinatura digital): clique em **Mais informações → Executar assim mesmo**.

Este repositório guarda só os instaladores; o código-fonte é privado.
